# GymFlow

A gym management system featuring student and administrator areas.

## Features
- User login
- Registration
- Student area
- Administrator area
- Database integration
- User authentication

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Database
The database file is available in the `banco/` folder.

## How to Run Locally
1. Install XAMPP
2. Place the project folder inside `htdocs`
3. Start Apache and MySQL
4. Open phpMyAdmin
5. Create a database
6. Import the `banco/gymflow.sql` file
7. Configure the database connection in the appropriate file
8. Access the project via your web browser

## Note
This project uses PHP and MySQL.  
GitHub Pages does not execute server-side languages ​​like PHP, nor does it provide direct support for databases; therefore, this repository serves to provide access to the source code and the database structure.
